About

I build AI that earns its keep — useful, efficient, and grounded in real human needs. I created French Coach, an AI-powered French learning app that turns a learner's own class notes into personalized, grounded practice through an agentic plan → generate → self-critique → revise loop — built to help a real person prepare for Canada's French exams. In my graduate research, I advanced continual learning so real-time AI can adapt to new data without costly full retraining, cutting computation while holding accuracy. Backed by an MASc and 5 IEEE publications, I care less about shipping models for their own sake than about the impact they create — for learners, for engineers, and for the systems people depend on.

Featured Project

🇫🇷 Agentic LLM App · Self-hosted models
French Coach

An agentic French study tutor that turns class notes into grounded practice. The core isn't a single prompt behind a text box — it's a multi-step Coach Agent (plan → generate → self-critique → revise) that reviews and fixes its own output before showing it, grounded in both the lesson and the CEFR syllabus. Runs entirely on self-hosted MiniCPM (text) and MiniCPM-V (vision) on Hugging Face ZeroGPU, with deterministic French NLP via spaCy and Postgres-backed persistence.
