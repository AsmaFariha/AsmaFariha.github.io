🇫🇷 French Coach

An agentic French study tutor that turns class notes into grounded practice. The core is a multi-step Coach Agent (plan → generate → self-critique → revise) that reviews and fixes its own output before showing it, grounded in both the lesson and the CEFR syllabus. Runs on self-hosted MiniCPM (text) and MiniCPM-V (vision) on Hugging Face ZeroGPU, with deterministic French NLP via spaCy and Postgres-backed persistence.
